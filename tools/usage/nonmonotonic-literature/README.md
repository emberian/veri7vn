# Retractable assumptions experiment

This untrusted reference model keeps signed source evidence separate from
provisional defaults. Missing evidence stays unknown; contradictory assertions
stay local to their atom. An exception retracts its dependent default results
when the bounded graph is recomputed. Receipts record support, assumption guards,
tenant, snapshot and time. A default cannot eliminate an unknown identity
candidate to manufacture a unique source answer.

Run the focused checks:

```sh
python3 -B tools/usage/nonmonotonic-literature/test_retractable_defaults.py
```

Eight checks include all 341 evidence assignments for up to four identity
candidates and their consistent completions. This is a design experiment, with
no specialist-panel score and no Oracle runtime integration. It accepts one
default per head, rejects recursive positive default dependencies and recomputes
the full active view. It is not an ATMS, WFS or ASP solver.

The [lane report](../../../project/lanes/LITERATURE-NONMONOTONIC-2026-10-27.md)
explains the source literature, ranked integration choices, proposed proof
obligations and remaining consumer work.
