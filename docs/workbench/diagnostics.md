# Diagnosis and reviewable repair

`Diagnostics.scala` explains actual native outcomes; it cannot create acceptance. Licensed HTML comes from the resident result path. Undefined arithmetic is a domain decline; budget/deadline is inconclusive; worker/handoff failure is not refutation. Unknown status is unavailable. Current `cancelled` cannot distinguish explicit cancellation from retired dependencies; preserve that information limit.

## Owner inspection frame v1

`RequestInspection.scala` parses bounded closed YXML describing native associations, not an execution capability or theorem. Root `veri7vn-request-inspection` has exactly `version=1`, `family=mathematics`, `status`. Its `identity` carries positive request, goal, interpretation, decision, capability, operation, semantic/executable generation and execution IDs. Execution identity is not the opaque ticket.

`reading(index,operation,input_bytes)` carries two physical byte literal spans. Operations: `sum`, `difference`, `product`, `quotient`, `subtract_from`. Alternatively, `reading-unavailable` distinguishes released/not_retained/invalidated; invalidated does not promise completed erasure. No original payload/private context/unrestricted source dump is included.

Reject wrong request/family/version/status/operation, duplicate/missing/extra fields, malformed children, size overflow and overlapping/out-of-bounds spans. Native producer uses actual Request/Language_Input/Literals/MathEntry objects. Missing assumption/source-coverage/runtime-impact fields mean unavailable inspection, never empty premises or complete coverage. `inspect_request` and host `requestInspection` share real result state; schema tests alone cannot qualify that linkage.

## Repairs

`Repair.propose` binds captured revision, original byte span, replacement, diagnostic, reason and explicit meaning choice. It validates with `Intake.patch` without writing. Changing `sqrt(x*x)=x` to `abs x` changes specification; adding `x≥0` restricts domain. Neither edit proves the theorem.

Apply uses `ManagedDrafts.edit` with exact manifest/revision/expected bytes. Stale heads and Forget reject; saved source still needs normal build/admission/qualification/publication. No independent repair database, auto-collected examples or inferred ground truth exists. Browser review preserves submitted text on failure; historical diagnostics never rebase onto current source.

## Native build failures

D43 `BuildFailure.scala` distinguishes `NativeReplay`/`NativeExport` as `build.replay_failed`/`build.export_failed`. A phase error is neither a counterexample nor an inferred obligation. The frame binds positive native source_revision/manifest IDs, optional physical span and governed message. Limits: 8192 UTF-8 frame bytes, 4096 message bytes; oversized messages become explicitly unavailable, and markup is rejected.

Native IDs are not managed revision hashes/paths. Before revealing/highlighting, the host joins failure request/prepared/source ownership to the exact captured input. `hasCurrentSpan` permits tentative review only with matching current manifest/revision and actual position. Historical views remain read-only; native producer→host association is a distinct qualification gate.

## Package change impact

Browser **Inspect affected package declarations** and CLI `impact NAME` consume the shared affected-set planner over individually inspected descriptor heads. Exact package/version dependencies yield paths to the selected target. Missing providers/unreadable descriptors are reported; ambiguous providers include every possible edge. Unavailable target means **not computed**, not an empty answer.

Bounds: 8192 drafts; 65536 declared edges, expanded provider edges and explanation-path nodes. Preflight before provider expansion/output allocation; one reverse BFS records paths. Overflow rejects the whole view. Reinspect after edits. This declaration graph does not predict source replacement contents, native invalidation, running work or erasure.

## Original build source positions

`SourceDiagnostic.locate` runs inside the host's governed captured-source callback. It checks original SHA256/size and physical UTF-8 boundaries, then returns path/revision, line/codepoint columns and Current/Historical/Unknown. It returns no source buffer; bounded decoding scratch is wiped. Slice offsets must include the original start exactly once.

Evidence is scoped in [validation](../../project/VALIDATION.md): parser/repair, source impact HTTP/CLI and expansion/path-bound checks passed; `retained.scala` passed original Unicode positions after edit and Forget denial (`RETAINED_SOURCE_DIAGNOSTIC_PASS`, stable `8b947c…`). These establish the live borrowed-source component, not native-ID association or restart reconstruction. Real resident inspection/browser checks separately exercise readings, refusal, provenance/restart and withheld HTML after cancellation/Forget. New Build composition remains unqualified until its actual producer/host/client consumer passes.
