## Additional source-ownership and diagnosis walkthroughs

**Reader recipe edit:** open Inventory.thy's recognized reader projection. Fields
show key column `item`, result column `shelf`, duplicate-key behavior `report conflict`
and scoped source adoption. Change selection to a declared snapshot. Preview exact
source patch and generated coverage obligations, then requalify missing/duplicate/
conflicting-row cases. The form does not edit data or expert source behind the
projection. Real syntax/parser is owned by native recipe implementation, not invented
by this mockup.

**Expert-only block and concurrent edit:** while a formula form is based on revision
r4, add an expert lemma in the same theory, producing r5. Apply the old proposal:
receive revision conflict; preserve r5 and unsaved field values; compare base/current/
proposed. Reparse r5 and regenerate the proposal; do not guess an offset or overwrite.
If expert source is invalid, retain development diagnostics while active release r3
remains usable. `design/workbench/check.py` exercises byte-span preservation,
concurrent-version refusal and stale-span refusal as a reference rule; it is not a
native parser/source-map implementation.

**Data-only growth:** import a new inventory snapshot, keep existing reader recipe
and compiled family bundle, validate schema/selection, build new source observation
identity and invalidate whole-snapshot consumers. A previous unique-row answer
becomes unresolved if a competing row is inserted. Show no new executable bundle
required while still showing acquisition/validation/index refresh costs. Switching
to an unsupported new carrier/kernel instead stages a bundle and its separate checks.
No index or selective reuse claim is inferred from a source hash.

**Ambiguous reading:** request “What shelf is Mercury on?” when a product and a room
share the name. Show both typed entity choices, original input spans and the separating
question. Selecting product creates an attributable interpretation decision; it does
not rewrite original text. A blocker on the room reading stays scoped. The chosen
reading's domain guards are checked before execution, while adopted source premises
remain visibly conditional. Bindings and ranking changes create new policy revisions.

**Search failure and partiality:** stop a multi-part search after its state/time budget.
Show searched scope and inconclusive status, retain independent accepted parts and
open dependent parts. Distinguish feasibility witness, upper/lower bounds and unknown
optimality. A “No solution exists” response is unavailable without separate adequate
coverage/evidence. Candidate scratch output can still be inspected without feeding
an authoritative accepted dependency.

**Forget recalled source and restore:** recall quotes a dated answer, then forget the
conversation source. Impact includes temporary reader, subject cache, uncurated gap
examples and learned derivatives. Pending dependent publication is cancelled; cached
followup fails current authority. Restore shows missing forgotten bindings and does
not execute old questions. An unknown committed action attempt stays in reconciliation,
not automatic Retry. Explicit execute-again is a new request with new effect preview.

## Executed design checks

`python3 design/workbench/check.py` passed:

- Thirteen scenario targets, three independent readiness axes and action previews.
- Reproducible generation of standalone `index.html` from view fixtures.
- Reference patch preserving all bytes outside its target span, including expert text.
- Refusal of both concurrent source revisions and stale expected span content.

Browser inspection used a temporary loopback-only static file server, not a product
server. All thirteen navigation/action controls were exercised through browser DOM,
showed three readiness states, and displayed an explicit inert action result.
Desktop inspection found no horizontal overflow. At 390×844, viewport and document
width were both 390; mobile screenshot was visually inspected. Hash navigation initially
did not update when navigating within the same document; adding a hashchange handler
repaired it. Screenshots `design/workbench/desktop.png` and `mobile.png` capture the
square-root repair view after that repair. The initial missing favicon produced a
404; a local data favicon removes that dependency. No external assets are requested.

Not established: native recipe parsing/patch validation, actual wire codec/authority
composition, browser editor behavior, real qualification/admission, deployment,
Film codec rendering/export, isolated workers, clean recipient rebuild, accessibility
trial or independent recipient usability. Host/authority integration and these
production consumers remain prerequisites for the workspace-client implementation.
D16 remote-adapter handoff extent and license/distribution closure remain explicit
root decisions; this design does not silently delete or implement them.

Product-copy review replaced visible native terminology with **Math check**,
**Example checks**, and **Use**, keeping exact Admission/Qualification/Deployment
