# Preimplementation gap audit

The 2026-10-15 source review established G01–G08 as integration requirements for architecture revision 2. These are design constraints and refuting cases, not migration or execution certificates. Detailed evidence: [domains](domain-gaps.md), [runtime](runtime-gaps.md), [workbench](workbench-gaps.md), [siblings](sibling-gaps.md).

## Conclusion

Keep open native HOL meanings, generated authority and finite typed executable families. Make claim scope, payloads, outcomes, routing, qualification, effects and lifecycle explicit before shared interfaces are consumed. Core migration includes tentative artifacts and author workflows; six siblings remain compatibility investigations.

## G01 — Claim scope is independent of assurance

Separate what a claim says, how it is supported and the artifact's lifecycle. Mathematical consequence, source report, finite-model prediction, measured test and finite-set optimum are different targets. A classifier calculation does not prove its real-world label; a score is not calibrated probability. Candidate code, fiction/help/acknowledgements remain useful response acts without universal truth claims.

C02 retains kernel, refined and explicitly enabled oracle routes; empirical tests are observations, not a fourth route. An opaque algorithm adapter cannot count as an owned native lift by calling itself an observation. Bind generated artifact claims to actual bytes/operation, not just placement metadata. Account separately for catalogue/toolchain, ordered pipeline and typed retained synthesis.

Owners: admission/authority/language/dialogue/growth. C02/C03/C05; PO-03/04/05.

## G02 — Semantic profiles and lossless inputs

Profiles declare native carriers, representation/codec laws, literals, numerical conventions, permitted conversions and materialization bounds. Affine points/deltas, dB, frames, SQL NULL/blob, exact probability, calendars and strings need their own laws; no scalar-plus-unit convention or closed universal value type suffices.

Retain original bytes and source maps beside normalized cue views. Refuting case: quoted `a b` versus `a  b` must hash differently; JSON positions and genotype case refer to original input. Owners: registry/interpretation/domains/math/authority; C01/C03; PO-01/02/03/07.

## G03 — Results need structure beyond one success flag

Carry ordered typed collections, prefix/completeness, artifact references, per-subgoal outcomes/evidence and dependency edges. SQL's first twenty rows are a prefix; a feasible graph witness is not optimality; one solved part does not finish the turn. Dependent parts consume structured bindings; independent parts may run concurrently. Compact rendering preserves scope.

Owners: authority/sources/plans/dialogue/graphs/domains; C03/C04; PO-02/03/04/06/09.

## G04 — Routing and refusal have scope

Distinguish no reading, missing dependency, ambiguity, inadmissible candidate and an obstruction to a particular claim. Blockers identify interpretation/premise/capability/request and discharge conditions. Alternatives cannot evade a failed check; unrelated justified readings or helpful response acts remain possible. Preserve addressed-personal-reader precedence and versioned routing traces; neither universal core-first nor indiscriminate fallback captures Oracle7.

Owners: interpretation/plans/dialogue/registry/regressions; C03/C04/C05; PO-01/04/08.

## G05 — Formal admission is not operational qualification

Qualification binds baseline/candidate, code, routing/bindings, learned state, panel/split/scorer, runtime and exposure. Measure added/wrong answers, false assertions, unwanted interception and latency. Regression repeats; fresh-heldout claims require fresh exposure; imported and aborted/spent exposure stay attributable. Admission cannot waive product qualification, nor tests prove a universal contract.

Feedback proposes a versioned policy; failed evaluation preserves the old active version. Nonpublishing evaluation isolates memory **and** disk learning. Retained objects declare request/session/shared scope.

Owners: lifecycle/registry/growth/performance/regressions; C01/C04/C05; PO-08/09.

## G06 — Observation and validation can perform effects

Connect/discover/preview/probe/qualify/poll/export are executor operations. Fixtures or selected live authority govern them. Acquisition retains event/receipt/evaluation clocks, origin/configuration, sequence/deduplication, quality, invalid/missing samples, windows and coverage. Owned background jobs have budgets, stop/restart and retirement rules. Measure whole-session interference and cancellation through quiescence.

Owners: sources/effects/connectors/host/performance; C04/C05; PO-03/09/10.

## G07 — State restoration, retirement and forgetting

Final arbitration precedes answer-derived adoption; utterance history is separate. Restore recorded typed state without rerunning questions/actions. Retirement denies new use; revocation denies access/pending publication; Forget additionally erases managed payloads and derivatives under explicit policy. Pins cannot revive expired/private readers. Include transcripts, caches, learned state, examples and pending work; curated copies require a decision. Tombstones retain no snippets; uncontrolled external copies are outside erasure.

Owners: effects/updates/lifecycle/dialogue/host/deployment; C01/C04/C05; PO-08/09/10.

## G08 — Preserve the author's improvement loop and explanations

Preserve decline→draft examples, feedback/requalification, user-tested tentative code, private recall, route explanation and local Film. Import original manifests/cards/panels/scorers/source/exposure inertly; known patterns generate editable proposals, unknown Python behavior leaves concrete port obligations. Explanations retain conditions, source/history and evidence; generated images are decoration. Remote media/publication require explicit payload/effect scope (D16), not default startup dependencies.

Packaged CPU-only reasoning and local authoring work with networking disabled: no mandatory external LLM/prover/CDN/download. Measurements determine memory claims. Owners: workbench/diagnostics/assistance/integration/handoff; C01/C03/C05; ACC-01/02/03/09/10/14/16.

## Consequence for fan-out

Every consumer names its G cases, exact interface and negative check. Coverage follows actual entry, inherited/virtual dispatch, state/effects, cancellation/expiry and restart—not manifests alone. Distinguish source-derived risk from reproduced defect and component tests from installed acceptance.
