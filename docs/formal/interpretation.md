# Interpretation and rendering

[Veri7vn_Interpretation](../../src/isabelle/language/model/Veri7vn_Interpretation.thy) addresses C03/C04, D20/D21 and PO-01/04. The input carrier is parametric. Literal spans always read original input; language spans may normalize, delete or expand. `well_mapped` requires valid spans and a contiguous complete partition. `literal_never_normalized` and `valid_slice_length` preserve literal meaning and boundaries. Unicode decoding and external source-map correctness require their own bridges; final emitted bytes remain TB-05. D31 supplies the shared numeric code baseline.

## Declared grammar

A typed rule table maps retained surfaces to native goals/open conditions. `elaborate_sound` associates each derivation with its actual rule, surface, span, goal and unchanged conditions; `elaborate_complete` retains every match. `recognize` distinguishes none/one/multiple readings; `ambiguity_retains_all` prevents priority from discarding ambiguity. A selection receipt records alternatives, choice and decision identity, proving membership rather than unexpressed human intent.

`Veri7vn_Grammar` adds token, partial-codec capture, sequence, choice and typed-projection combinators. Soundness composes independent relational meanings. Capture assumes the codec's returned-value soundness but proves span/consumption bounds. `specialist_literal_sound` connects the value to its original absolute span and rejects missing delimiters. Fixtures preserve spaces/newlines, allele case, title/pronoun distinction, deleted language segments and ambiguous entity roles.

`Natural_Mathematics` recognizes bounded signed-integer sum/difference/product/quotient/subtract-from phrases, retaining exact ASCII byte captures. Its 256-byte limit is operational. The interpreted request constructs `closed_expression_run` and the parameterized `closed_expression_meaning` requirement before any answer exists. Trusted policy supplies the actual family instance and executable pin.

`Natural_Source_Rows` preserves observed-count/full-total ambiguity. Explicit observed-row questions bind an existing declaration's acquisition/query/schema/population requirements; totals retain a coverage obligation. The relation child maps exact UTF-8 whole-question patterns and versioned reader declarations to `SnapshotRelationQuery`, including retained-v1 `who wrote TITLE?` behavior. Multiple property bindings remain multiple readings; no guessed aliases or implicit case folding occur. Under D40, utterance/declaration roles remain distinct even when physical input storage is shared.

## Structured and byte rendering

`Veri7vn_Rendering` consumes the authority's actual claim/outcome/subgoal/blocker types. `claim_rendering_correspondence` reconstructs every semantic qualifier, condition, dependency and generation from structured display. `render_parts` preserves historical per-goal requirements, slots and partial outcomes; it cannot turn old Accepted tags into current authority.

`authoritative_render` selects visible bindings through current `binding_licensed`; `authoritative_render_live` connects each emitted assertion to such a binding. Interpretation blockers apply across fallback capabilities. Help, questions, fiction, instructions and candidate/artifact delivery have separate structures, with embedded assertions using the same licensing path. Untrusted draft commentary is excluded.

`HTML_Bytes` proves canonical entity escape/decode laws. `Controlled_Templates` assigns native meanings to fixed integer/rational sentences; `Checked_Statements` reparses and compares the full typed view before escaping. These laws neither decode arbitrary Unicode nor prove that a value was computed.

D34’s fixed display bridge attaches the actual math instance/generation, execution pin and statement-checker pin. It compares original captures and whole AST, immutable native input/outcome predicates, saved result view and exact sentence. Its `fixed_math_display_contract` includes grammar derivations, capture semantics, expression reflection, outcome view/rational semantics and conditional sentence/escape law. Per-output premises require the actual same-request family association, then current authority/access checks at byte handoff. Recipient output must project authorized conditions rather than expose private native-premise XML.

`answer_relation_question_sound` preserves shared relation semantics under `DeclaredFiniteSnapshotOnly`: duplicate equal witnesses use distinct-value semantics, absence remains snapshot-relative, and incomplete/schema-rejected replies cannot become negative world answers.
