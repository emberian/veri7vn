# Native admission

[Native admission](../../src/isabelle/admission/native_admission.ML) implements C02 and the native attachment boundary for PO-03/04/08. Registry membership identifies a candidate; only the opaque accepted record supplies a consequence. It retains the actual theorem, certified target, immutable generation/handle, route and `Exact_Native_Proposition` scope. Current execution and publication require separate authority checks.

## Acceptance

The gate compares the complete typed proposition, ordered contextual hypotheses, explicit premises and sort hypotheses; rejects unresolved flex-flex pairs; and checks theorem/target ancestry against the receiver generation. Exported assumptions must remain in the requested sequent. `Thm.consolidate` completes pending derivations; `Thm_Deps.all_oracles` audits transitive oracle dependencies. Kernel admission permits none. An oracle route requires both its declared dependencies and the independently installed allowlist. Proof skipping always rejects; failure cannot downgrade the route.

Trusted image installation establishes the baseline theory and approved axioms. Ordinary descendants must preserve its entire axiom table, including unused axioms. Controlled `define`/`define_command` invoke Isabelle's native definition package and carry the exact successor policy after checking the exported definition theorem. A worker cannot install policies, execute ML, or authorize its own extension. Privileged plugins change this boundary.

Validation caches use immutable theory identity or generation/handle identity, never names or propositions. Bounds are 64 theories and 256 theorem audits per policy; target and condition checks still run on every admission. Checked native transfer handles legitimate trimmed certificates without replacing ancestry checks.

The accepted scope licenses the exact native proposition. English world-truth, completeness, optimality or probability labels require their own native target and licensed projection. Conditions remain conditions. A generic executable attachment is not provided: each finite bundle must bind its actual implementation, representation, dispatcher, code setup and refinement contract.

## Inert producers

`family_certificate.ML` checks a Boolean-list count: at most 1,000 elements, claimed count 0–1,000, fixed receiver simplification and a two-second deadline. Its theorem states that finite computation only.

`proof_transport.ML` accepts inert proof terms bounded to 100,000 bytes, 20,000 nodes, depth 128 and five-second reconstruction. Framing is checked before recursive decoding. Unavailable proof bodies, oracle nodes and undeclared hypotheses reject. Isabelle's receiver-side `Proof_Checker.thm_of_proof` reconstructs the theorem, followed by full admission. Export expands worker-private references relative to the actual receiver; concrete class nodes use Isabelle's class algebra. Checker closures retain at most four contexts and have generation release hooks. Host stack, memory and process limits remain separate.

## Native-to-authority association

`Native_Descriptor.register` projects an accepted kernel consequence into internally allocated IDs. Target, premise and sort resolvers return actual native objects; conditionality derives from retained hypotheses/premises/sorts. It rejects oracle records. Proof-only metadata uses `NoExecution`; the request still pins its control bundle. Explicit executable requirements and refined/oracle routes apply their own execution checks.

D35 persistent authority requires `register_produced` and complete managed provenance. The fixed authority adapter derives its generated claim/event closure from that opaque descriptor; caller projections cannot attach evidence. IDs locate objects, not portable proofs. Restore reconstructs and rechecks native meaning before reassociation.

`Managed_Provenance` owns controlled public facts, exact-source definitions, full-source developments and bounded source proofs. Source producers parse their own protected original slices and retain the resulting context, source and ordered parent closure. Canonical named facts undergo normal admission. Caller-supplied theorems or provenance labels cannot substitute for a producer. See [development](native-development.md) and [recovery](native-recovery.md).

Construction scopes register fresh developments, consequences and source leases before interrupts resume. Abort releases only those products; commit transfers them at the consumer's publication boundary. Shared parents and independently retained sources survive. Final context release clears native roots, generation mappings, admission audits and proof-checker closures; external plugin references remain their owners' responsibility.

## Identity and conditions

D40 shares source/input ownership across consumers. The host advances its durable counter before installing an opaque allocator block. IDs use positive bounded `IntInf`; generation and input maps contain numeric locators only. Checked source/context fragments install atomically with forward and reverse uniqueness. Equal bytes under different input identities remain distinct owners. Invalidation denies access immediately; physical disposal waits for all leases and removes only that owner's associations.

D34 specialization retains the original parameterized requirement and every premise occurrence. Output-dependent conclusions and condition templates need actual native substitution and occurrence correspondence; Isabelle may merge equal instantiated hypotheses only with justified equality/equivalence. Fixed-family correspondence does not establish this general bridge.

D43 candidate artifacts remain separate from theorem admission. The source-family adapter consumes the private confirmed-acquisition ticket and the exact reservation, attempt, input, source, generation and executable instance. It retains original wire/manifest, typed batch, observation and immutable query. Query failures/blocked traces remain outcomes. The implementation theorem covers execution; no per-row theorem is fabricated. Releasing the association invalidates returned aliases. Streamed-source, declared-language, output-slot, cost and final assembly consumers require their own qualification.

## Evidence and limits

[Admission tests](../../tests/admission) exercise exact targets, hidden/declared hypotheses, premises, forbidden oracles, proof skipping and bounded certificates. [Managed-development evidence](../../tests/admission/development/evidence/managed-development-20261016) records the source replay→descriptor consumer, rollback, parent release and source Forget. Scoped publication evidence is under `tests/admission/evidence/scoped-publication-20261015`. [AC-01](consumer-closure.md) targets transported conditional sequents.

These establish named component checks, not all PO-03/04/08 obligations. TB-01 covers faithful native attachment; TB-02 covers selected code/runtime association. Actual authority acknowledgement, durable reconstruction, emitted bytes and complete source dependencies remain distinct consumers. Hashes, codec roundtrips and successful compilation are not native theorem evidence.
