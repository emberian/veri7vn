# Updates and qualification

`PackageUpdates` computes conservative transitive invalidation over exact source revisions. Dependencies include whole snapshots—absence, ranking and aggregates—not only positive witnesses. Reuse compares complete package/data/session/read/clock-origin/event/configuration pins; repoll cannot refresh an event. Native change classification belongs to the build service; ordinary content changes request data/recipe revalidation, while session-setup changes conservatively require compilation.

Publication uses the existing qualification reservation/start/result and `StageQualifiedPublication` path through one durable writer. Expected-previous-slot checks implement atomic replacement. Replacement preserves historical pins without implying revocation. D44 Forget must invalidate native/private owners as well as storage; `forgetStorage` alone is incomplete. Selected transfer retains exact graph fingerprint, private-ancestry choices and exposure attribution.

## Recovery and observer identity (D55, D57)

Request roles are `initial-qualification-request` and `update-qualification-request`; result roles are their distinct measured observations. All are nonassertional controlled recipes with executable pin and empty raw theorem sequent. Request association is the unique child slot; result association is observation evidence ID. Publication slot is separate.

TestObservation semantic pins identify the installed qualifier observer/code context, not a subject theorem. Candidate/baseline native generations and complete snapshots remain explicit dependencies. Checked observer-ID fragments install atomically; a session installation owns shared mapping lifetime. Old candidate-generation snapshots cannot be retagged as observer-context observations.

Result wire v2 uses `initial-qualification/2` or `update-qualification/2`; initial request v2 uses `initial-qualification-request/2`, update request v1 `update-qualification-request/1`. Initial request v1 rejects; update v1 is bound-only. Result v1 is not reinterpreted as v2.

Prepared/Reserved/Started derive from exact checkpoint membership/reservation. Reconstruction preserves identities without reserving, charging, exposing or dispatching again. Started without committed result restores interrupted. Fixed deterministic structural/admission verification can recheck its captured contracts; historical behavioral timing requires its original authenticated run source, never remeasurement.

## D43 Build-to-qualification composition

Initial v2 supports template/bound variants. A template retains the actual prepared BuildRequest lease, original export intent, exact Build request/goal/slot/execution, observer context and qualification IDs. It contains no candidate generation or observation. Only the acknowledged output of that exact Build slot can bind it, after complete source/manifest/parents/profile/setup/intent/plan comparison. Binding preserves qualification IDs and original edge while adding the actual subject generation.

Templates restore through BuildRequest owners; bound requests through candidates. Exporters retain these actual owners independently until commit. The logical-context bridge retains both initial qualification and candidate owners, exposing their actual development/policy/exports/generation/dependencies. It is not a publication token: Search additionally requires acknowledged current publication and licensed exports, and independently owns receiver/proof descendants.

`Initial_Qualification_Metadata.thy` supplies fixed adapters within the parent's single generated universe. Native producer/codec fixtures do not establish the paid service/restart/publication join; that composition remains separately qualified. Behavioral measurement and its capture boundary are specified in [behavioral evaluation](behavioral-evaluation.md), native reconstruction in [recovery](native-recovery.md).
