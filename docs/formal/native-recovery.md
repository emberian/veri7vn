# Native recovery correspondence

Recovery reconstructs native objects under the actual installed image, compares their meaning with protected committed material, and installs checked identities atomically. Digests and codecs establish transport integrity, not logical truth. C02 re-admission supplies kernel consequences; family contracts supply their declared refined-execution routes.

## Native objects and identity

`Native_Recovery_Check` checks committed capability, slot hashes, workspace/association/generation, image/context closure, fixed recipe, complete sequent and ordered premise/sort-ID partition. The sequent retains exact typed target/proposition, hypotheses, premises, sorts and flex-flex pairs. Saved IDs remain metadata; native objects are freshly reconstructed.

Public named facts use a fresh approved `Managed_Provenance.public_image`, not an arbitrary equal-looking private theory. Private definitions/developments use actual protected source owners, encodings/spans, bindings and ordered logical parents. Canonical names select facts only within reconstructed contexts. Image closure includes the actual boot build manifest, baseline ancestry and code setup; privileged installation with an arbitrary label is not qualification.

The shared graph separates canonical construction owners from aliases: each saved context ID has its own logical wrapper/parents even when theories are shared. Internal cache IDs never enter restored claims. Typed context leases retain ancestors independently of descriptors. Final unreachable-owner pruning releases construction sources and removes numeric mappings.

D40's shared input pool interns one actual owner per workspace/source ID, rejects conflicting bytes/encodings, and preserves distinct IDs for equal bytes. Base ownership, consumer leases and invalidation are separate. Source/context identity fragments install in one checked batch with forward/reverse uniqueness; failed batches publish none. Fixed checker functors belong to the trusted image, not worker input.

## Replay profiles

`veri7vn-managed-expert-replay/1` records a topological DAG of approved roots, exact definitions and source replay nodes with ordered import locators, original full-input IDs and spans. Qualification/restoration invoke the same `P.replay_source`/`P.named_theorem`, admission and full-sequent comparison.

D47 adds Proof nodes: exact target source, bounded inert proof wire and complete sequent. The convenience producer requires no external conditions; its complete-sequent overload preserves hypotheses/premises/sorts and rejects flex-flex constraints. Conditions are bounded to 128 per list, aggregate hypothesis/premise terms to 20,000 nodes, classes to 128 per sort and names to 512 bytes. Native proof transport imposes its additional structural bounds.

Expert recipe v1 rejects Proof nodes. V2 selects Produced or exact Named descendants with proof ancestry; wire/sequent use lowercase hex. Aggregate decoded proof/sequent bytes are bounded to 45,000 and encoded recipe to 100,000 before allocation/export. Restoration rechecks certificates; it never reruns heuristic search or consumes old execution tickets.

Replay construction runs interruptibly outside the graph lock while temporary leases protect reused parents/sources. A short commit checks graph version/liveness; failure aborts only fresh construction-scope roots. Consequence/source scopes also release temporary named facts without retiring shared developments. Per-call liveness visits each development once, rejects cycles and rechecks observed owners; final authority acknowledgement must still serialize later revocation.

## Scoped ownership

`V7SCOPE2` carries a canonical AuthorityWire original plan and currently required subset. Only required originals retain physical payloads; inactive identities/order can remain without erased bytes. Exact UTF-8, binary and native-term labels participate in identity. Bounds: header 1 MiB; originals 2 MiB total, 64 records, each 1 MiB; whole closure 16 MiB. Nested family material is byte-preserved, not Base64-expanded. Larger inputs require another bounded association, never truncation.

The fixed Scope checker validates installed image/code, exact checkpoint original/subset and approved receiver before acquiring shared leases. Families independently verify nested correspondence. SessionInput reconstructs a graph-only native parent and actual original row without dispatch/adoption; transcript access additionally requires recorded membership and read authority.

D74 separates cancelled execution from retained historical verification. Math/Search outputs currently depend on request recipes; active Scope denial must not become fresh execution eligibility or destroy independently retained evidence. Inert original-source/recipe capsules, historical retrieval and active-inventory migration require coordinated consumers. Until qualified, unsupported reconstruction fails closed rather than fabricating a consumed execution.
