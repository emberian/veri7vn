## Continue the lab: behavior, examples and conditions

Identity, constant zero and absolute value agree at zero; identity/absolute value agree at one but differ at minus one. Examples reveal mistakes without proving universal equivalence.

```sh
V7_BRANCH=$("$V7_COMMAND" locate --tutorial branch-review)
"$V7_COMMAND" launch --state "$V7_STATE" --surface source -- import-native branch-review "$V7_BRANCH" workshop-branch-import-1
```

In `Branch_Review.thy`, `branch_result x = abs x`; the commented all-integer identity proposal fails at −1. Choose between restricting identity to nonnegative inputs and changing implementation to return `x`. Use **Review a source change → Preview → Apply/Cancel** to retain that decision against the captured revision. These controls review edits; they do not run proof search or turn the commented proposal into a theorem.

For historical behavior, follow [paint intake](first-specialist.md). Compare original source and migration obligations before changing units, rounding or domain guards. Updating expected answers to fit a new implementation does not establish preservation.
