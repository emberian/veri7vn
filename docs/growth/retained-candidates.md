rechecked on the new samples. Identical sample vectors do not collapse programs.
The returned observation records preserve expected and actual optional values,
including undefined evaluation. No sample record becomes a universal theorem.

`Retained_Mathematics` is a pure policy, not a production service. Context keys are
comparison data, not native ownership. The actual consumer must acquire a live
owned context, bound the retained library and expression sizes, charge execution,
and route each sample through the installed mathematical bundle. Its existing

This reuses the installed interpreter, without compiling a new expression type or
application bundle. Durable retention belongs to the existing managed artifact
lifecycle; this policy cannot create an admission, qualification or activation.

Nonpublishing evaluation accepts an immutable library and returns new immutable
candidate/observation values. It has no persistence or mutation callback. A caller
must not retain those returned values into a shared workspace implicitly. The
fixture checks a later sample rejects a stored constant, compatible identity is
reused without fresh atoms, context changes exclude old forms, empty evidence is
not retainable, and evaluation leaves subsequent baseline evaluation unchanged.
