# Native search strategies

`Veri7vn_Search_Fn(Tickets)` searches actual Isabelle proof states under one prepared certified target and pinned receiver/worker generations. Canonical catalogue names resolve once to actual managed theorems. Fixed actions include retrieval/application, selected simplification, conjunction splitting, implication introduction and assumption. No worker methods, ML, Isar or evaluator callbacks are accepted.

A consume-only private ticket binds the exact instance, operation, profile/pin, request/input and paid work. FIFO exploration preserves alternatives and records subgoals plus advanced/failed/blocked/timed-out action results. It performs no live-state deduplication. Success exports bounded inert `Proof_Transport` bytes for independent receiver reconstruction/admission. Exhaustion, budget stop, deadline and cancellation are not refutation. Remaining time below Isabelle's one-millisecond timeout threshold refuses work rather than starting an unbounded action.

`Veri7vn_Strategies` models finite worklists, per-goal replies/blockers/refutations and cumulative positive fuel charging. It proves cancellation does no work and candidate/route-failure recording creates no refutation. The ML producer is not yet proved a refinement of that scheduler. Future pruning needs [observation/continuation equivalence](../formal/composition.md), not target equality alone. Structural work cost bounds expansions, frontier, actions, successors and catalogue size; it is not an OS time/memory theorem.

## Source and recovery consumer

`Veri7vn_Search_Request_Fn` parses an exact retained UTF-8 slice as a native proposition, checks managed catalogue consequences against resolved worker facts, and prepares the fixed producer. `prepare_child_owned` derives the span from the actual protected native child and claims that association atomically. Request-only construction scopes register input/prepared roots before interrupts resume; abort releases only fresh products.

Produced proof bytes pass through `Managed_Provenance.prove_from_slice_owned`, which reparses the original target and audits the reconstructed theorem before publishing a source-owned consequence. Full-sequent support preserves declared conditions. Search output certificates bind original child identity, actual receiver, proof context, source bytes/span, complete sequent and distinct private proof identities.

`restore_owned` requires checked reconstructed source/context owners and exact native child identity, bytes, encoding, span, target, catalogue and limits. Numbers do not reconstruct owners. D74 requires historical output verification independent of cancelled execution Scope; active inventory, live cleanup and output capsules must migrate together. Restoration never dispatches search or recreates a ticket.

## Proposals and breadth

Ranking and failed tactics do not establish truth. Original w32 catalogue/toolchain, w37 pipeline and w482/w486 retained-library workflows remain distinct migration obligations.
