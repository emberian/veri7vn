# Contextual routing and dialogue

`Veri7vn_Dialogue` consumes the shared interpretation, request, subgoal, blocker, binding, selection, session and renderer types. It adds versioned precedence policy, not another registry. Interpretation selection comes first: all eligible readings survive clarification, and selection receipts must contain the exact alternatives. Precedence compares exact requirement/scope/conditions/pins or an approved native conversion; it cannot infer human intent.

`addressed_capabilities=None` permits ordinary routing. `Some allowed` restricts sources; `Some []` forbids fallback. `dialogue_current_select` uses actual current authority, freshness, D56 shared parent access and child access. Interpretation blockers survive cross-capability fallback. `dialogue_adoption` proposes the existing `StageAdoption` only after final arbitration and `adoption_permitted`; durable authority acknowledgement owns visibility.

## Original behavior and resident path

Unresolved pronouns require clarification. Dependent parts share structured context, but final guards must precede adoption.

Temporary recall-reader expiry does not impose universal conversation expiry. Upstream saved-specialist readers default to seven days, bounded 1–365, with wall-clock expiration. The regression in `test_workbench_lifecycle.py` records the old expired-reader ordering defect, not proof of repaired native followups.

The current native registry supports fixed `math/1`, not the whole original registry. `inspect_routing_details` exposes actual candidate indexes, operations and original spans through the paired native/host protocol; the older `inspect_routing` retains its index-only interface. Policy functions must share the metadata frame's single generated universe; client checkpoints cannot supply authoritative state. D46 source/domain constructors join existing reservation/execution/result/recovery paths. Source inspection additionally needs protected source/declaration ownership.

Conversation-aware inspection retains expected native session/version and exact pending bytes; `discardConversation` erases those inputs. The fallback model requires actual previous-goal membership, same requirement, selected reading, unblocked state and live child, plus an explicit reading-decline allowlist. Blocked, failed or cancelled outcomes never grant fallback. The native model and 24 regression lemmas pass; runtime multi-specialist fallback remains uninstalled. The shared `specialists`, `route` and `explain` handlers pass against real native selection/execution and Forget; CLI dispatch compiles.
