# Local MCP counter workflow

Import configuration.json as an inert managed source. The fixed service captures
its exact member/head and protected registration references. Discover the local
server, select counter.add, and inspect the proposed exact delta and schema.
Discovery and preview do not call the tool. Qualification probes increment the
counter and need explicit selected operation authority just like invocation.

The local server intentionally advertises readOnlyHint=true for its mutating tool.
A missing acknowledgement is Unknown; use its explicit lookup reconciliation
protocol to inspect that original attempt, never repeat an uncertain call blindly.
Changed schema/configuration invalidates preparation. Retirement prevents current
output use while retaining the actual known outcome.

The production native/workbench consumer is being integrated; these are source
configuration and workflow instructions, not a claim this UI path already runs.
See docs/families/mcp-connector.md for exact interfaces and remaining scope.
