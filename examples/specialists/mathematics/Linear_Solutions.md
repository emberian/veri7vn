# Exact linear solution sets

Optional Mathematics_Linear_Bundle parses `linear a_num a_den b_num b_den`, solving rational ax+b=0: `linear -2 3 5 7`→{15/14}; `linear 0 1 0 1`→all; `linear 0 1 3 1`→none. Nonpositive denominators reject.

solve_linear_complete/linear_pair_complete cover every candidate/degenerate case. Managed request/output retain original bytes/context/pin/cost; optional checker compares exact generated result, cross-instance/retired origins reject. Native consumer qualification, D46 registration, licensed display and recovery remain open; this is not general symbolic solving.
