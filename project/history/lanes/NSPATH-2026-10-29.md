# Directed shortest paths, 29 October 2026

Owner: Sol shortest-path lane. Code checkpoint `951a178` is pushed. There are no
specialist-panel numbers for this operation. It is an experimental supplied-graph
capability, not an Isabelle theorem or Mini qualification.

`graph.shortest_path` now runs through the Rust library/JSON dispatcher, generic
PyO3 bridge, Python operation discovery and the NativeService/NativePool HTTP
path. It returns an exact finite minimum walk weight, unreachable, or unbounded
below for a complete caller-supplied directed i64 multigraph. Stable edge IDs are
input positions. Checked i128 sums are encoded as decimal strings. Missing edges
are absent only in the supplied graph, without any external-world coverage claim.

Nonnegative source-to-target corridors use an integer heap; signed corridors use
bounded Bellman-Ford. A negative cycle affects an answer only if reachable from
the source and able to reach the target. Independent Rust certificate checks
establish the following graph-local statements:

- A finite edge-ID path attains the declared distance. Labels cover exactly the
  source-to-target corridor, label(source)=0, and
  label(v)<=label(u)+weight(u,v) on every corridor edge. Telescoping bounds every
  source-to-target walk below by label(target), proving the attaining path minimal.
- An unreachable set contains the source, excludes the target, and is closed
  under every supplied outgoing edge. No source-to-target walk can leave it.
- An unbounded witness supplies a source prefix, a nonempty closed negative cycle
  and a target suffix at the same anchor. Repetition gives arbitrarily low weight.

These statements are checked by handwritten Rust; they are not HOL theorems.
The actual consumer is the experimental operation dispatcher and native HTTP
provider. A specialist adapter, panel scoring and production admission remain.

Caller `Limits.vertices`, `edges`, `search_ms` and `request_bytes` constrain the
operation. Named operator settings `graph_work` (5,000,000 default) and
`graph_reply_bytes` (256 KiB default) bound graph work and encoded certificates.
Validation, graph-sized construction, search, checking and direct capped encoding
share one cooperative budget. No intermediate serde JSON value is built. Standalone
checking has its own budget. Allocator calls, individual heap operations and Rust
destruction remain non-preemptible; this is not a hard wall-clock guarantee.
The pure Rust API accepts AtomicBool cancellation; generic Python/HTTP requests do
not expose a cancellation handle. Host request/reply envelope limits still apply.

NativeService reconstructs reasoning JSON with compact separators and
`ensure_ascii=False`. This preserves compact encoding of the integer/string
certificates without claiming arbitrary floating-point lexical identity for other
providers. The adapter checks strict result variants, endpoint and witness shapes,
edge-ID walks, exact integer encodings and matching advertised operator bounds.
Pure request IDs provide correlation; repeated calls recompute rather than promise
durable replay.
