## What is authored

`bio.align_pairwise` compares supplied DNA with explicit mode and integer
scoring. Rust-Bio 4.0.1 produces a path. Independent Rust code checks interval
consumption, each match/substitution label, affine gap runs and replayed score.
A second implementation computes the optimal score using four rolling i64
rows and checks equality. This supports global, local, and whole-query versus
local-reference alignment, with zero-based half-open positions and forward
orientation only. Ties are accepted, with no uniqueness claim.

This is useful computed-and-independently-checked behavior, without a formal
proof, organism identification, clinical interpretation or sequence design.
There are **no theorem statements and no new specialist-panel numbers**.

## Integrated interface

Central integration added `oracle-bio` as an optional PyO3 provider and native
workspace member. It follows the science provider API:

```rust,ignore
catalog() -> serde_json::Value
call(request: &str, limits: &Limits, cancel: &AtomicBool) -> Result<String>
```

Dispatch envelope: `{"operation":"bio.align_pairwise","arguments":{...}}`.
Arguments are `query`, `reference`, `mode`, `scoring`, optional `ambiguity`.
Mode is `global|local|query_global`. Scoring is the four-field object
`match_score,mismatch_score,gap_open,gap_extend`. Ambiguity is `reject` by
default or `always_mismatch`. Errors expose `code()` for host mapping.
The typed `align_pairwise` and `check_alignment` APIs are also public.

The catalog declares the fixed caps and all mode/strand/ambiguity conventions.
The operation is exposed through worker dispatch, discovery and optional
enablement under the shared service process policy. Central qualification
exercised actual PyO3 and HTTP/CLI consumers, as recorded below.

## Decisions and evidence

Current official [Rust-Bio 4.0.1 documentation](https://docs.rs/bio/4.0.1/bio/alignment/pairwise/struct.Aligner.html)
and [source](https://docs.rs/bio/4.0.1/src/bio/alignment/pairwise/mod.rs.html)
were consulted. The pinned version charges `gap_open + (k-1)*gap_extend`.
Both score and gap convention are explicit. Ambiguous IUPAC bases never score
a match under `always_mismatch`, even when letters are identical; the wrapper
normalizes backend edit labels accordingly. RNA, whitespace, gaps, empty input
and unrecognized symbols are refused. See the README for complete constraints.

All sequence/cell/buffer-estimate checks precede provider normalization and
matrix allocation; a separate request-byte check precedes JSON parsing. Limits
are 4,096 bases/string, 1,048,576 cells/pass and 16 MiB estimated buffers,
lowerable by the operator. This is two serial bounded quadratic passes, without
an exact process RSS bound. Rust-Bio cannot be interrupted inside its call;
hard deadlines belong to the host's process containment.

shows complement/translation/GC, Mendelian/HW, and growth/CFU/dilution coverage
already exists. Alignment adds a separate capability. No existing panel is
