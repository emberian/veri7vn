## What it does and what it establishes

Inputs are an explicit extension path and lowercase SHA-256, an absent output
path and an explicit requested profile list. It copies only that extension and
the reviewed fixed service import closure. It never copies an interpreter,
whole repository, image, corpus, credential, private config, journal or cache.
The dynamic runtime sibling loader is included. Dormant Engine-only imports in
the shared transport/operations files are enumerated; the native entrypoint
constructs `Operations(None)` and never invokes those paths.

The component adapter is `native_runtime_adapter.py`; the appliance host helper
retains `native_runtime.py`. The explicit package list follows that production
rename, avoiding the former duplicate basename when component paths are added
before appliance paths by another embedding host.

The generated launcher locates payload from its own path, enters Python
`-I -B -S` isolation, verifies every payload's digest/size and the complete file
set, resolves only this bundle's extension and passes the operator's external
runtime sidecars through the existing service parser. It does not need the
working directory, `PYTHONPATH`, Oracle7 or Mini. Requested profiles remain
unqualified in its manifest; service startup and central actual-artifact tests
check real exports/catalogs. The manifest records declared code version and
source hashes, with no inference that the artifact came from that source.
Extension API version is observed in actual qualification.

Directories publish with atomic no-replace rename on Linux/macOS. Archives have
fixed gzip/tar metadata and exclusive publication. The archive and directory are
two destinations, not one transaction; archive publication may survive a later
directory collision. Paths reject traversal and symlink components. Local hashes
are unsigned integrity metadata, not interpreter/build attestation. CPython
3.12+, matching OS/architecture/ABI and linked system libraries remain host
requirements; no network installation or root deployment occurs.
