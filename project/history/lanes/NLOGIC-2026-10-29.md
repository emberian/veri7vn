# NLOGIC — native stable-model provider, 29 October 2026

Owner: Sol nonmonotonic lane. Owned paths only: new `native/oracle-logic/**`
and this report. No upstream writes, shared manifest/lock/host/PyO3 edits,
subagents, commits or builds/tests by this lane. Central runner owns execution.

No specialist panel numbers yet. Standalone prototype qualified on Linux;
no workspace, PyO3, HTTP, shared-host, appliance or package consumer exists.
No theorem statements: all new code is handwritten Rust, not Isabelle-verified.
Each full model receives an independent GL reduct/least Horn fixpoint check.
UNSAT, consistency absence and exhaustive enumeration remain explicitly
solver-trusted without certificates. Inconsistency never creates vacuous truth.

Changed files: standalone Cargo manifest; `src/lib.rs` (bounded JSON contract,
closed tenant/snapshot scope, checker, numeric ASP encoding, decoding and
answers); `src/process.rs` (bounded native clingo process adapter);
`tests/semantics.rs` and `tests/solver_boundary.rs`; five JSON examples; README
with sourced backend comparison, runtime limits and integration plan.

Default queries use a consistency solve and opposite-polarity SAT/UNSAT probes,
not complete model enumeration. All solves share the parse/encoding deadline,
checker-work and aggregate pipe-byte budget. Explicit enumeration is optional.
Interrupted later probes preserve checked one-sided facts and valid completed
answers. If any checked model refutes a prior UNSAT, all absence-dependent
conclusions are globally revoked and answers rebuilt from checked witnesses.
Exact process-exit agreement with SAT/UNSAT/completion/count is required;
unknown, interrupted or conflicting summaries fail closed.

Decision: contained native clingo first. MIT license; C++14/CMake build.
Varisat CDCL is credible but requires correct completion plus loop handling,
encoding/proof interpretation and interruption work. Naive exponential
candidate enumeration is confined to the independent test oracle. Local
Lifschitz 2008 and Elkan 1990 papers and primary solver sources informed this
choice; links and licensing evidence are in the crate README.

Actual central qualification: **18 tests passed**, plus formatting and
all-target clippy with `-D warnings`. Ten semantic tests include 1,225 two-atom
programs × four candidate models = 4,900 independent oracle checks. Six process
boundary tests cover exit conflicts, interrupted partial evidence, three-query
backend inconsistency, blocked stdin/timeout, stdout overflow and in-flight
cancellation; lifecycle fixtures assert the owned child PID is gone afterward.
Two actual-clingo tests were explicitly run, not counted from ignored status:
36 one-atom rule pairs match the independent oracle; 60 independent defaults
(2^60 models) plus a forced query succeed under a two-witness cap while explicit
enumeration is inconclusive. No broader performance or panel score is claimed.
See [qualification receipt](../../native/evidence/2026-10-29-logic-validation.json).
