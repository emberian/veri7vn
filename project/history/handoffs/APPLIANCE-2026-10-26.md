## Expectations to challenge

- Equal units do not imply equal quantities: height cannot satisfy width without an explicit connection.
- An invalidated admission cannot authorize changed source bytes or survive only in a persisted cache.
- A later reader cannot turn a recorded kernel contradiction into an ordinary coverage gap and answer anyway.
- Conversation state and ledger describe the final delivered answer, including replacement and refusal.
- Retrying exactly the same request does not execute it twice. A changed body with the same request ID is refused.
- A complete appliance receipt binds source revision, local patch hashes and actual store bytes. LFS pointer files are not payloads.
- New specialist counts require registry and native consumer integration; parser fixtures alone are not a shipped panel score.
