## Making the capabilities usable

relation readers. Versioned implementation IDs and these catalog entries are
different counts. A declaration is not evidence that ordinary wording reaches
the capability. Ember's question about what the system does highlights the next
product gap: expose discoverable operations with required inputs, units,
assumptions, source references and measured examples, alongside conversational
querying. Derive that view from actual runtime registration; directory counts
and a potentially stale Workbench index cannot establish live availability.
The existing `tools/usage/discovery/` guide is a starting point, not that API.
