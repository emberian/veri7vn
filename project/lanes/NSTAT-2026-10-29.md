## What it does

`statistics.linear_regression` takes supplied feature/response rows, an explicit
intercept decision, fixed positive loss weights, names/units and model
assumptions. Sequential faer SVD computes a fit without forming a normal-equation
inverse. The result retains numerical rank, singular spectrum, conditioning,
original-row residuals, leverage, stationarity and influence diagnostics.

Classical inference requires independent Gaussian errors with variance inversely
proportional to the supplied weights, plus the declared correct conditional
linear mean. It supplies coefficient covariance, Student-t tests/intervals and
conditional-mean prediction. Individual-observation intervals require explicit
new-observation precision on the same input scale and the same independent
Gaussian noise model.

HC3 instead computes sandwich covariance on the transformed weighted design,
with asymptotic normal Wald tails. It requires independent mean-zero errors,
correct mean, fixed weights and usual asymptotic regularity; it does not require
the weights to be true precisions. It rejects individual-observation intervals
because coefficient covariance does not identify new noise. README derives both
weighted formulas and explains global weight-scaling invariance.

Rank deficiency, zero residual degrees of freedom, rounding-sized residual
variation, excessive condition number, failed stationarity or HC3 unit leverage
withhold inference with explicit reasons. Rank-deficient candidates are labeled
minimum-norm representatives, not identified coefficients. No causal inference,
formal verification, data-dependent feature selection, clustered covariance,
estimated-weight uncertainty, sampling, Bayesian model or GLM is implied.

## Exact mathematical statements

No theorem statements or axioms were added. These are implemented floating-point
statistical formulas, conditional on caller assertions, not proved HOL results.
For normalized positive diagonal W, supplied X/y and full numerical column rank:

1. beta is the SVD weighted least-squares candidate for
   `sum_i W_ii*(y_i-X_i*beta)^2`, within the declared rank policy.
2. Classical covariance is `s^2*(X'WX)^-1`, with
   `s^2=sum_i W_ii*e_i^2/(n-p)`; t intervals assume independent Gaussian errors
   with variance proportional to inverse weight and the correct conditional mean.
3. HC3 is `Z^+*diag((sqrt(W_ii)*e_i/(1-h_i))^2)*(Z^+)'`, with
   `Z=sqrt(W)X`, `h_i=diag(Z Z^+)_i`; its normal inference is asymptotic.
4. Mean prediction variance is `x_new' Cov(beta) x_new`. Classical independent
   observation variance adds `s^2/w_new_normalized` only when explicitly requested.

The implementation builds covariance square-root factors directly from SVD
vectors and sums outer products in supplied units.
