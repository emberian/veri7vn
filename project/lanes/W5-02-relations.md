# Lane W5-02: one verified kernel for all 161 relation readers (handoff, 2026-10-17)

Oracle7 answers "who wrote / who directed / when was ... born" questions through 161 relation specialists
(`upstream/root/specialists/rel-*`). They are all one program (`RelationOrganV2`, two of them with a pronoun
guard, `RelationOrganV2G`) run with different data: which question patterns ("readers") each one reads, which
Wikidata property each pattern asks for, and which kinds of things count as being in its domain. This lane
replaces that program's decision with ONE function proved in Isabelle/HOL, `decide_spec` in
`src/extract/relations/Relation_Reader.thy`, and turns each specialist's configuration into HOL data
(`Relation_Tables.thy`, 161 entries) that a check script compares with the shipped files.

### The 11 homonym wrong answers are now declines

Each was a title shared by several works, where the popularity ranking put the wrong one first. Under this
kernel every one is declined ("I can't verify the ... of ... from my records"), read from
`var/relations/parity/*.items.jsonl`:

rel-albums: Know Your Enemy, Big Thing, Infinite, Score (performer), Speaking in Tongues, Score (label),
Land of the Free; rel-novels: Hyperion; rel-songs: Two of Us, Promise, Unholy. All eleven reply with path
`veri7vn:relations>DECLINE:P175|P264|P577`. They are also 0 wrong under each linker alone (runs below).

The rule that does it: a forward answer now needs every LINKED in-domain sense (up to 24 senses from the
linker) that holds a stored value of the property to hold the same value, not only the at most three senses
the shipped popularity rule keeps. Item for item against the shipped organ's run: 22 items it got right are
now withheld (genuinely ambiguous names such as John Holt, Cedar Lake, Lulu, Mount Royal; with names_v1 alone the
rule costs 20), and 45 items it missed are now right (the stand-in linker on 18 readers).

## What is proved (session `Veri7vn_Relations`, receipts below)

Theorem statements, verbatim from `src/extract/relations/Relation_Reader.thy`:

```
theorem answer_stored:
  assumes ans: "decide_spec sp f attempts = Answer (s, p, v)"
  shows "\<exists>a r. a \<in> set attempts \<and> attempt_values sp f a = Some (s, p, v) \<and>
          r \<in> set (readers sp) \<and> rkey r = key a \<and> p = rprop r \<and> slot_ok a \<and> \<not> restates f v \<and>
          (dir a = Fwd \<longrightarrow>
             (\<exists>c. c \<in> set (mineof sp a) \<and> qid c = s \<and> dom_complete c \<and>
                (\<forall>c' \<in> set (candidates a). complete c') \<and>
                (p, v) \<in> set (rows c) \<and> v \<noteq> Blank \<and>
                (\<forall>c' \<in> set (mineof sp a). set (vals p c') = {v}) \<and>
                (\<forall>c' \<in> set (candidates a). domain_member sp c' \<and> vals p c' \<noteq> [] \<longrightarrow> set (vals p c') = {v}))) \<and>
          (dir a = Inv \<longrightarrow>
             (\<exists>c \<in> set (subjects a). domain_member sp c \<and> qid c = s \<and> label c = v \<and> v \<noteq> Blank \<and>
                (p, label (hd (candidates a))) \<in> set (rows c) \<and>
                (\<forall>c' \<in> set (subjects a). domain_member sp c' \<longrightarrow> qid c' = s)))"

theorem decline_stored:
  assumes dec: "decide_spec sp f attempts = Decline (p, s)"
  shows "\<exists>a c r. a \<in> set attempts \<and> dir a = Fwd \<and> in_table sp (key a) Fwd (idx a) \<and> slot_ok a \<and>
          r \<in> set (readers sp) \<and> rkey r = key a \<and> p = rprop r \<and>
          c \<in> set (candidates a) \<and> qid c = s \<and> domain_member sp c \<and> \<not> (guard sp \<and> pron c)"

theorem disagreeing_senses_never_answer:
  assumes fw: "dir a = Fwd"
    and c1: "c1 \<in> set (candidates a)" and c2: "c2 \<in> set (candidates a)"
    and d1: "domain_member sp c1" and d2: "domain_member sp c2"
    and n1: "vals (prop_of sp (key a)) c1 \<noteq> []" and n2: "vals (prop_of sp (key a)) c2 \<noteq> []"
    and differ: "set (vals (prop_of sp (key a)) c1) \<noteq> set (vals (prop_of sp (key a)) c2)"
  shows "attempt_values sp f a = None"
    and "live sp a \<Longrightarrow> \<not> dropped sp (key a) (dir a) (idx a) \<Longrightarrow> allc a \<Longrightarrow> mineof sp a \<noteq> [] \<Longrightarrow>
         attempt_decline sp f a (prop_of sp (key a), qid (hd (mineof sp a)), pron (hd (mineof sp a)))"

corollary answer_senses_agree:
  assumes "decide_spec sp f attempts = Answer (s, p, v)"
  shows "\<exists>a \<in> set attempts. attempt_values sp f a = Some (s, p, v) \<and>
    (dir a = Fwd \<longrightarrow> (\<forall>c1 \<in> set (candidates a). \<forall>c2 \<in> set (candidates a).
       domain_member sp c1 \<and> domain_member sp c2 \<and> vals p c1 \<noteq> [] \<and> vals p c2 \<noteq> [] \<longrightarrow>
       set (vals p c1) = set (vals p c2)))"

lemma silent_meaning:
  assumes "decide_spec sp f attempts = Silent"
  shows "kind_conflict f \<or> (\<exists>a \<in> set attempts. step sp f a = Halt Silent) \<or>
    (\<forall>a \<in> set attempts. transparent sp f a) \<or>
    (guard sp \<and> (\<exists>a \<in> set attempts. \<exists>d. attempt_decline sp f a d \<and> snd (snd d)))"
```

In words:
- **answer_stored**: an answer comes from one matched phrasing of a reader in THIS specialist's table and names
  that reader's property. A forward answer names a linked in-domain entity whose fetched rows hold exactly that
  value; every selected in-domain sense holds exactly that value; and every linked in-domain sense that holds any
  value of the property holds exactly that one. An inverse answer names the one in-domain subject the fetch
  found holding the top sense as a value.
- **decline_stored**: a decline names a reader of the table, its property, and a linked in-domain entity of a
  matched forward phrasing (recognise-then-decline).
- **disagreeing_senses_never_answer**: two linked in-domain senses with different stored values mean that phrasing
  never answers; with the shipped selection keeping an in-domain sense, it marks a decline.
- **answer_senses_agree**: the same at the level of a whole turn.
- Also proved and collected by the marker: `decline_meaning`, `incomplete_meaning`, `silent_meaning`,
  `step_silent`, `attempt_values_sound`, `attempt_values_sound_inv`, the walk invariants, `in_table_reader`,
  `spec_of_Some` and the selection lemmas.

The premises `complete` and `dom_complete` (the fetch returned every stored fact of the property; the classes,
their subclass-of closures and the held excluded properties are the shipped walk) are claims the untrusted
fetch makes; nothing in HOL establishes them.

## Untrusted parts, named

- The recognizer: `relation_spec_v2.normalise`, the shipped compiled reader regexes, slot text, `kind_conflict`,
  `PAST`, all imported read-only (`tools/relations/fetch.py`).
- The linker: names_v1 (its popularity column is a fact-degree proxy, see TRIAGE-2) or the stand-in; up to 24
  senses (the shipped 6 first, in their order, then further senses).
- The fetch: classes, closures (the shipped depth-8, 12-parent walk), held excluded properties, labels, rows; it
  asserts completeness.
- The restate words and the V2G pronoun flag (`fetch.py`).
- The reply rendering (dates through the shipped `_show`, population formatting, the receipt sentence) and the
  JSON layer `src/extract/relations/main.sml` (lane W5-01's parser).
- The domains file for the 52 domains the release did not ship (`var/linker/o7root/relstore/relation_domains_v2.json`,
  reconstructed from manifests; tables_check checks it against the manifests too).
- The classification (`tools/relations/report.py`).

## What it does not do / remaining

- **Mined-pattern fallback not modelled.** 23 specialists also carry `patterns.json` (relation_spec_v1.answer),
  used when the readers find nothing. The kernel is silent there. Measured: the fallback answers 0 of the 18,976
  panel items over the shipped store (`probe_shipped.py` records the path), so the panels cannot see it; a
  question outside the panels could.
- Inverse phrasings (only key 26, spouse) are modelled and proved but never exercised: every panel item is forward.
  The kernel additionally checks from the subjects' own rows that each holds the top sense's label, which can only
  withhold more than the shipped organ.
- The 1,814 absent-property items need a richer store (relations_v2 did not ship).
- No head run, so the exam's composite criteria stay INCOMPLETE.
- Build history: `attempt_values_sound_inv` (an `auto` that never finished) and `walk_silent_inv` needed three
  builds in all; both were finished with fully explicit steps, not weakened.
