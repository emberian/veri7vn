## Versioned local source context

The implementation in `tools/dialogue/state.py` and `tools/dispatch/dispatch.py` consumes
an actual final producer receipt containing family, specialist, store content
version, row, local subject identity, surface, role, and predicate. It does not
invent a QID, infer a person from answer text, or link that subject into another
store. A complete same-predicate follow-up uses one question evaluation in the
original source family. The returned answered receipt must match the entire
stored identity, including version and predicate. Mismatch, disappearance, or
an accepted refusal stops the turn. Ordinary final guards and ledger handling
still apply.
