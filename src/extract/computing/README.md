# The computing family, end to end

This folder carries nine shipped Oracle7 specialists as one program: `networking`,
`embedded`, `cyber`, `linux-v2`, `git`, `sql`, `python`, `python-r2` and `robotics-v2`
(`upstream/root/specialists/<id>/organ_*.py`). It follows lane G's pattern
(`src/extract/quantity/README.md`): the arithmetic, the tables and the decisions to
decline are written in Isabelle/HOL with proofs, Isabelle turns them into Standard ML,
and the MLton compiler that ships inside Isabelle turns that into one binary,
`var/computing/bin/computing`. No Isabelle process runs when questions are answered.

## What is proved and what is trusted

| Part | File | Status |
|---|---|---|
| IPv4 blocks, masks, broadcast, private ranges, smallest prefix for N hosts | `Networking.thy` | HOL, proved |
| Embedded timers, UART, UBRR/CTC rounding; cyber keyspace, brute force, Base64, entropy; robot wheel, encoder, PWM, differential drive, 2-link arm | `Numerics.thy` | HOL, proved; entropy, pi, cos and sin through Isabelle's verified interval arithmetic |
| chmod modes, umask, cron counting, signal table; git intent table | `System.thy` | HOL, proved |
| Python 3.12.3 reference: 856 rows, name resolution | `Pyref_Table.thy` (generated by `gen_pyref.py`), `Pyref.thy` | HOL; the table itself is checked by `tables_check.py` |
| A small SQL engine (CREATE, INSERT, SELECT with WHERE, GROUP BY, ORDER BY, LIMIT, aggregates, SQLite NULL rules) and a syntax checker | `Sql.thy` | HOL, proved in parts (sorting, WHERE, aggregates, unknown columns) |
| Export, self tests, oracle check | `Computing_Export.thy` | the build fails if any listed theorem uses an oracle or a self test fails |
| Table transcription check | `tables_check.py` | a Python check, not a proof |
| Reading numbers and words out of English, the SQL lexer | `../commons/commons.sml`, `recognizer.sml` | **untrusted**, hand-ported from the organs |
| JSON framing | `main.sml` | **untrusted** |

What it cannot do yet: Python's float rounding differs from exact rounding on ties
(the kernel rounds the exact value half-even); SQL REAL is an exact fraction here, a
binary double in SQLite. An entropy over 62 symbols (letters and digits) is refused,
because the interval arithmetic does not reach six digits for it (see the S15b lane
report for the deferred fix).

## Build and run

```sh
python3 tools/dev/check-native --session Veri7vn_Computing \
  --session-root src/extract/computing --expect 'VERI7VN_COMPUTING PASS' --timeout 600
python3 -B src/extract/computing/tables_check.py
sh src/extract/computing/build.sh
echo '{"id": "1", "q": "What signal number is SIGKILL?"}' | var/computing/bin/computing --specialist linux-v2
PYTHONDONTWRITEBYTECODE=1 python3 -B tools/parity/harness.py \
  --answerer "var/computing/bin/computing --specialist {id}" \
  --specialist networking,embedded,cyber,linux-v2,git,sql,python,python-r2,robotics-v2 \
  --split both --out var/computing/parity
PYTHONDONTWRITEBYTECODE=1 python3 -B src/extract/computing/score.py   # cross-check against the organs
```
