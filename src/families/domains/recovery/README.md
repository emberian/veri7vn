# Domain recovery contract (D59)

Factory/host integration is not installed. Closed Controlled_Recipe roles require the actual pin:

| Profile | Role | Material |
|---|---|---|
| quantities/1 | domain-request | Nonassertional, empty evidence sequent |
| quantities-runtime-refinement/1 | domain-output | Complete target, ordered conditions, accepted implementation/model/display contracts and same-request output; **RuntimeRefinement**, not an answer theorem |

Authenticated committed material/current checkpoint must match parent/request/goal/subject/operation/output slot, whole template, source/condition references, generations, image/pin and all digest slots. Each accessible protected owner needs exactly one complete set; hashes alone are insufficient.

Only the fixed factory constructs protected_domain_request. Its condition selector stages actual receiver/source through the shared pool, parses the full original proposition and checks role/context/owner/span/ancestry before issuing opaque checked_condition with leases. Staged developments are not live; ordinary prepare cannot stage them.

One batch interns authenticated old condition IDs only when full proposition/role/source bytes/encoding/span/receiver match. Standalone sources retain independent leases; graph/source fragments install atomically. Private postinstall construction consumes each witness once, rechecks liveness/correspondence and acquires leases before publishing. No generic numeric authority map is added.

Reconstruction compares full request/template/contracts/conditions; fixed execution checks saved output/target/display without replaying charged workflows/tickets. SourceDomain additionally retains original acquisition/cell/unit conversion, never a naked Domain request.

Required fixtures: same-ID changed proposition, wrong receiver/source/span/role/pin, witness reuse/conflict, shared-condition interning, surviving sibling/evidence leases, source invalidation, selective Forget and actual host restart. Shared decoder, bundle/request/display/gate and factory consumers need their own qualification.
